# OtobusOtomasyonProje
 Bu projede, kullanıcıların otobüs firmaları üzerinden sefer arayarak bilet satın alabilecekleri bir bilet alma uygulaması geliştirdim. Uygulama, C# dili ve Windows Forms mimarisi kullanılarak oluşturulmuş olup, veri yönetimi ve saklama işlemleri SQL Server ile gerçekleştirilmiştir.  Kullanıcılar;  Seferleri tarih, kalkış ve varış noktalarına göre filtreleyebilir,  Uygun seferleri görüntüleyip koltuk seçimi yapabilir,  Seçilen koltuklara göre bilet satın alabilir,  Satışlar sistemde kayıt altına alınarak raporlanabilir.  Admin paneli üzerinden:  Sefer ve otobüs bilgileri eklenebilir/düzenlenebilir,  Satılan biletlerin takibi yapılabilir.
